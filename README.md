# Lectora Fics 💗

Lector nativo de **AO3** y **FanFiction.net** para Android que traduce los fics al español con IA,
siguiendo el contexto: fandom, personajes, relaciones, resumen, párrafos anteriores y un glosario por obra.

## Qué hace
- **Explorar** por categoría y fandom (AO3 y FanFiction.net), con filtros: orden, clasificación, completos, idioma.
- **Buscar** por palabras, o pegar el enlace de un fic para abrirlo directo.
- **Ficha** de cada obra: resumen, notas, advertencias, relaciones, personajes, etiquetas y capítulos.
- **Lector** con temas (rosita, claro, sepia, noche, negro), letra, tamaño, interlineado y texto justificado.
- **Traducción** automática por capítulo, con caché (releer no gasta). Mantén presionado un párrafo para ver el original.
- **Biblioteca**: leyendo (con progreso), guardados y descargados para leer sin internet.
- **Descargar + traducir** la obra completa para leerla offline en español.
- Inicio de sesión en AO3 para obras restringidas.
- Verificación de Cloudflare de FanFiction.net resuelta dentro de la app.

## Proveedores de IA (tu propia API key)
Google Gemini (nivel gratis), Anthropic Claude o cualquier API compatible con OpenAI.

## Compilar
GitHub Actions compila el APK en cada push y lo publica en Releases.
